# Retail Shelf Automation (FlejesAuto)

Sistema de automatización en C# / .NET para la gestión, actualización y procesamiento de flejes y etiquetas de productos en estanterías de retail.

---

## 📋 Requisitos del Sistema

* **.NET SDK** (compatible con tu versión de proyecto)
* **Visual Studio 2022** (o Visual Studio Code)
* **Git** instalado en el sistema

---
