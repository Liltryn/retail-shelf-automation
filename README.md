


# Retail Shelf Automation (FlejesAuto)

Sistema configurable de automatización desarrollado en **C# / .NET** diseñado para la gestión, actualización, formateo e impresión de flejes y etiquetas de precios en estanterías para todo tipo de tiendas retail.

---

## 🚀 Características Principales

* **Generación Flexible de Flejes:** Automatización en la creación y formateo de etiquetas adaptables a distintos formatos de estantería.
* **Soporte Multitienda/Genérico:** Configuración modular para adaptarse a los catálogos y plantillas de cualquier comercio.
* **Reducción de Errores Operativos:** Minimiza fallos manuales en el cambio masivo de precios e identificación de productos.
* **Auditoría y Registros:** Captura de eventos e historial de procesos para resolver inconsistencias rápidamente.
